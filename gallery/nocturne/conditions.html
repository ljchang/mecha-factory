Conditional fields

Change the format, tick the box, put a big number in attendance — the fields below react. The server re-evaluates every one of these rules on submit.

op = "in". Required only when shown: the browser did not show it, so the server cannot insist on it.

op = "ne".

op = "is_true", not "present" — an unticked checkbox is present and false, so `present` would show this whatever the answer.

op = "gt". A non-numeric value on either side does not hold, rather than erroring.

op = "present" means submitted and not empty. An empty string is absent, or every optional field would satisfy its own dependants.
